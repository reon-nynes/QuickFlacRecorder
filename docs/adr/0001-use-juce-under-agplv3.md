# Use JUCE under AGPLv3

QuickFlacRecorder will use JUCE 9.0.3 and CMake for its native desktop interface, audio input, and bundled FLAC writing. The user chose JUCE's AGPLv3 route for a free public open-source recorder and accepted changing the initial GPLv3 project license to AGPLv3, rather than using a commercial JUCE license or assembling a different GUI and audio stack. The decision was accepted during the design interview; the license and build setup will change after final design confirmation.
